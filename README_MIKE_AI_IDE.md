## The Repository

This repository contains **Mike AI IDE**, an advanced development environment built on the Visual Studio Code Open Source foundation, enhanced with cutting-edge AI capabilities and developer productivity features.

## Mike AI IDE

Mike AI IDE is a completely independent fork and enhancement of the Code-OSS repository, featuring:

- **Advanced AI Integration**: Built-in AI coding assistants and intelligent code completion
- **Enhanced Performance**: Optimized for modern development workflows
- **Custom Extensions**: Pre-configured with essential development tools
- **Independent Brand**: Completely separate from Microsoft and VS Code branding
- **Privacy-Focused**: Your data stays with you

## Key Features

- 🤖 **AI-Powered Development**: Integrated AI assistants for code generation, debugging, and optimization
- ⚡ **Enhanced Performance**: Faster startup times and improved memory management
- 🔧 **Pre-configured Tools**: Essential extensions and configurations out of the box
- 🎨 **Custom Themes**: Beautiful, productivity-focused themes
- 🔒 **Privacy First**: No telemetry, no data collection
- 🌐 **Multi-Language Support**: Enhanced support for modern programming languages

## Building and Running

### Prerequisites

- Node.js (version 18.x or higher)
- Python 3.x
- Git

### Quick Start

```bash
# Install dependencies
npm install

# Build the IDE
npm run compile

# Start in development mode
npm run watch

# Run Mike AI IDE
npm start
```

### Production Build

```bash
# Create production build
npm run build

# Package for distribution
npm run package
```

## Development

### Building from Source

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mikepfundt/mike-ai-ide.git
   cd mike-ai-ide
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Build the project**:
   ```bash
   npm run compile
   ```

4. **Run in development mode**:
   ```bash
   npm run watch
   ```

### Project Structure

- `src/` - Source code for Mike AI IDE
- `extensions/` - Built-in extensions and AI features
- `build/` - Build scripts and configuration
- `resources/` - Icons, themes, and assets
- `scripts/` - Development and build utilities
